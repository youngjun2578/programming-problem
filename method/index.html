문제 생성·검증 방식

이 사이트(%SITE_NAME%)의 문제는 어디서 가져온 것이 아니라 직접 만든 생성 규칙(템플릿)으로 매번 새로 만들어집니다. 문제를 만드는 방법과 채점·검증 방법, 결과를 판정하는 기준을 이 페이지에서 설명합니다. 지금은 개발 초기 단계라 영역마다 임시 문항 유형만 있습니다.

1. 진단 영역과 진행 방식

진단하는 영역

  • 프로그래밍: C·C++·Python·Java 가운데 한 언어로 된 코드를 읽고 실행 결과를 정확히 예측하는지 봅니다.
  • SQL: 표와 SQL 문을 함께 읽고 조회 결과를 정확히 예측하는지 봅니다.

영역 구분은 NCS 전산직 필기 대비를 위해 이 사이트가 정한 것입니다. 실제 채용 시험은 기관마다 출제 구성과 난이도가 다르며, 이 진단은 특정 기관의 시험과 같다고 보장하지 않습니다.

진행 방식

  • 영역마다 정해진 수의 문항을 풉니다. 문항마다 보기를 고르면 바로 다음 문항으로 넘어가고, 이전 문항으로 돌아가 답을 바꿀 수도 있습니다. 정답은 마지막에 한꺼번에 공개합니다.
  • 화면 위쪽 진행 바에서 남은 문항과 경과 시간을 확인할 수 있습니다.
  • 문제는 풀 때마다 숫자와 코드가 새로 만들어집니다. 무료 진단은 한 번이며, 이용권이 있으면 새 문제로 여러 번 다시 풀 수 있습니다.
  • 문제는 풀 때마다 숫자와 코드가 새로 만들어지므로 여러 번 다시 풀어도 됩니다.

리포트에서 확인하는 내용

  • 수준: 영역별 정답률과 풀이 시간을 바탕으로 안정 / 보완 필요 / 집중 필요 3단계로 표시합니다.
  • 틀린 패턴: 고른 오답이 어떤 실수에서 나오는 값인지에 따라 진단합니다. (예: 반복문의 끝값을 포함하는지 헷갈리는 경향)
  • 문항별 해설: 문항마다 풀이 과정을 보여 주며, 결과를 인쇄하거나 PDF로 저장할 수 있습니다.
  • 무료와 이용권: 무료 진단에서는 영역별 요약(정답률, 평균 시간, 수준)과 1·2번 문항 해설을 볼 수 있습니다. 영역별 상세(틀린 패턴, 취약 유형)와 3번 이후 해설, 이를 포함한 인쇄/PDF, 새 문제로 다시 진단은 이용권(한 번 결제, 구독 아님)으로 이용할 수 있습니다.
  • 문항별 해설: 문항마다 풀이 과정을 보여 주며, 결과를 인쇄하거나 PDF로 저장할 수 있습니다.

2. 문제를 만들고 채점하는 방법

  • 직접 제작한 템플릿. 유형마다 문제의 구조와 문장 틀을 직접 작성합니다. 외부 기출문제나 문제집의 문장을 옮겨 오지 않습니다.
  • 시드로 문제를 만듭니다. 진단을 시작하면 서버가 새 시드(문제 번호)를 정하고, 그 시드로 숫자·코드·문장 틀을 골라 문항을 만듭니다. 같은 시드에서는 언제나 같은 문항이 나옵니다.
  • 채점은 서버에서 합니다. 브라우저에는 문제와 보기만 보내고 정답과 해설은 보내지 않습니다. 답을 제출하면 서버가 서명된 세션 토큰에서 시드를 꺼내 같은 문항을 다시 만들고, 그 문항의 정답으로 채점한 뒤 리포트를 돌려줍니다.
  • 오답은 흔한 실수에서. 오답 보기는 임의의 숫자가 아니라 "반복 범위를 한 칸 넓게 봄", "조건 하나를 빠뜨림"처럼 실제로 자주 하는 실수를 계산으로 재현해 만듭니다. 각 오답에는 어떤 실수에서 나온 값인지 표시(실수 유형)가 붙어 있고, 결과 리포트의 "틀린 패턴"은 이 표시를 근거로 합니다. 실수로 만들 수 있는 오답이 부족할 때만 정답 근처의 값을 "계산 실수" 보기로 채웁니다.
  • 풀 때마다 다른 문제. 숫자, 코드, 문장 틀이 매번 달라집니다. 같은 유형도 문장 틀을 3가지 이상 두어 같은 문장이 반복되지 않게 합니다.
  • 표는 가상 자료. 문제에 나오는 표의 값은 문제를 위해 만든 가상의 값입니다.

3. 정답을 검증하는 방법

정답은 사람이 입력하지 않고 문제를 만들 때 계산으로 함께 정해집니다. 여기에 더해, 사이트를 배포하기 전에 자동 검사(npm run validate)를 실행하며 하나라도 실패하면 배포 파일이 만들어지지 않습니다.

  • 유형마다 문제를 3,000번씩 생성해, 정답 보기가 정확히 하나 있는지 확인
  • 보기 5개가 화면에 보이는 형태로 서로 겹치지 않는지 확인
  • 문장·보기·해설·표·코드에 NaN, 정의되지 않은 값 같은 비정상 값이 없는지 확인
  • 해설에 정답 값이 실제로 나오는지 확인
  • 모든 오답에 실수 유형이 붙어 있는지, 근접값으로 채운 오답이 지나치게 많지 않은지 확인
  • 문항 세트를 5,000개 만들어 영역마다 서로 다른 유형으로 구성되는지, 같은 세트 안에서 문장이 겹치지 않는지, 같은 시드에서 같은 세트가 나오는지 확인

자동 검사는 계산과 형식의 오류를 막지만, 문장이 어색하거나 해설이 부족한 경우까지 모두 잡아내지는 못합니다. 이상한 문제를 발견하면 아래 문의처로 알려 주세요.

4. 결과를 판정하는 기준

영역마다 문항 수가 적으므로 규칙을 단순하게 두었습니다.

  • 안정: 영역의 문항을 모두 맞힘. 단, 문항당 평균 시간이 권장 시간의 1.5배를 넘으면 보완 필요로 표시합니다.
  • 보완 필요: 정답률 60% 이상
  • 집중 필요: 그 미만

권장 시간은 영역마다 문항당 90초로 잡은 연습용 기준입니다. 전체 점수는 참고 정보로만 보여 줍니다.

5. 개인정보 안내

답안과 풀이 시간은 채점을 위해 서버로 전송되며, 채점이 끝나면 저장하지 않습니다. 이 사이트는 쿠키와 방문 분석 도구를 사용하지 않습니다. 로그인은 이용권 구매와 이용에만 필요하며, 로그인한 경우 계정 ID와 이용권 상태만 저장합니다. 자세한 내용은 개인정보처리방침에서 확인할 수 있습니다.

현재 이 사이트에는 광고가 없습니다. 광고를 도입하게 되면 설명 글 페이지 위주로 두고, 문제 풀이 화면과 결과 화면에는 두지 않는 것을 원칙으로 합니다. 광고 제공 사업자는 쿠키를 사용할 수 있으므로, 게재 전에 개인정보처리방침을 먼저 갱신합니다.

6. 이용 시 유의사항

  • 연습용 진단이며, 결과는 합격 여부나 실제 시험 점수를 예측하지 않습니다.
  • 영역당 문항 수가 적어 같은 실력이라도 결과가 달라질 수 있습니다. 여러 번 풀어 경향을 보는 것을 권합니다.
