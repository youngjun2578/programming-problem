예시 문항

다음 Python 코드를 실행하면 화면에 무엇이 출력되는가?

count = 0
for i in range(1, 9):
    if i % 3 == 0:
        count += 1
print(count)
  1. ①2
  2. ②3
  3. ③8
  4. ④9
  5. ⑤18

정답은 ① 2입니다. range(1, 9)는 1부터 8까지이므로 3의 배수는 3과 6뿐입니다. ② 3은 끝값 9까지 들어간다고 보았을 때 나오는 값으로, 이런 보기를 고르면 영역별 상세 리포트(이용권)에 "반복 범위 오류" 패턴으로 표시됩니다.이런 보기를 고르면 리포트에 "반복 범위 오류" 패턴으로 표시됩니다.
